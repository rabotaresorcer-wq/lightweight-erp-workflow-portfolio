# Privacy and Scope

## Repository Boundary

This repository is a public-facing portfolio case study. It is intended to demonstrate workflow design, process logic, and operational thinking.

It is not intended to publish:

- a live ERP database;
- real client records;
- private contact details;
- internal company documents;
- credentials, tokens, or API keys;
- production automation configuration;
- confidential pricing rules beyond simplified demo logic.

## Data Handling

The card visuals use anonymized or synthetic demo values where sensitive information would otherwise appear.

Any visible names, event IDs, revenue figures, costs, dates, or operational examples should be treated as portfolio-safe demonstration data rather than live business records.

## Safe Publishing Checklist

Before publishing or sharing this repository publicly, check that:

- no private credentials are included;
- no real phone numbers, emails, social handles, or client names are included;
- no internal file links or private Drive URLs are included;
- no unpublished business-sensitive formulas or automation secrets are included;
- no local machine paths are exposed in the README;
- the nine final cards remain unchanged unless a separate edit was approved.

## Future Work

If code, Apps Script, n8n workflows, or templates are added later, they should be reviewed separately before publication.

Use environment variables or placeholders for all credentials and account-specific identifiers.
